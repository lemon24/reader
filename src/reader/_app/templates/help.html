Help

Welcome to reader, a feed reader web app!

reader allows you to subscribe to web feeds, read articles, and keep track of the ones you've read or liked.

Feeds

A web feed is an internet document used to get updates from websites such as blogs, web comics, or podcasts.

When you subscribe to a feed, reader checks it regularly to get the latest articles (unless the feed is disabled).

Adding feeds

To add a feed, paste the feed or website URL on the Add feed page.

If you use a website URL, reader will discover any standard feeds it links to and suggest them to you.

If that doesn't work, you can usually find if a website has a feed by looking in its header or footer for this icon , or for links called feed, RSS, or Atom.

Importing / exporting feeds

You can import feeds from a subscription list exported by another feed reader.

To export your own feeds as a subscription list, click the icon on the Feeds page.

Entries

An entry is an item from a feed – an article, a podcast episode, etc.

To read an entry, click its title on the Entries page. Some feeds only include summaries, not the full content; click the icon to go to the original article.

Entry flags

Each entry has a read and an important flag. Among others, they are used to filter entries on the Entries page.

You can set the flags by using the toggles below the entry title.

mark as read / mark as unread
Mark the entry as read. Hides the entry from the default entries view.
mark as important / clear important
Mark the entry as important. Important entries are never deleted. (Currently, entries are never deleted, but an upcoming feature will clean up old entries.)
don't care / clear don't care
Mark the entry as explicitly not important. Hides the entry from the default entries view without marking it as read. (An upcoming feature will allow identifying "noisy" feeds based on this.)

Enclosures

Some entries have external resources you can download, for example an audio file of a podcast episode.

Click the icon to download the first enclosure of an entry, if any. {% endblock %}
